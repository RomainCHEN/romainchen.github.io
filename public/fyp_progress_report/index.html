02

The Solution

AI generates.
Teachers decide.

A single-agent system that generates KET/PET exercises within strict vocabulary constraints. Teachers review, edit, and approve before anything reaches students.

Configure → Generate → Validate → Review → Export

  • Vocabulary-locked generation (official Cambridge word lists)
  • Deterministic post-generation validation
  • Classroom-ready export (Word, PPT, PDF)

06

Validation Pipeline

Generate, Validate, Retry

  • Prompt Engine builds request from template
  • DeepSeek generates structured JSON
  • Validator checks every word against Cambridge list
  • Pass → show to teacher for review
  • Fail → retry (max 2), then Claude fallback
  • Teacher has final approval power
