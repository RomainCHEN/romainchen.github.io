Prompt Engineering

Three-Layer Constraints

  • Layer 1: Prompt-level vocabulary constraints + few-shot examples
  • Layer 2: Temperature 0.3 + JSON structured output
  • Layer 3: Deterministic validator checks every word

Key finding: LLMs cannot self-validate. They report compliance even when violations exist.

Discovery: "Constraint Drift"

Model satisfies structural constraints (correct JSON, right length) but subtly violates pedagogical constraints (B1 vocabulary in A2 exercise).

Clusters in negation/contrast contexts where model reaches for higher-register words.

→ Three-layer approach emerged as direct response

07

Validation Pipeline

Generate, Validate, Retry

  • Prompt Engine builds request from template
  • DeepSeek generates structured JSON
  • Validator checks every word against Cambridge list
  • Pass → show to teacher for review
  • Fail → retry (max 2), then Claude fallback
  • Teacher has final approval power
