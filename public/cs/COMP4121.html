The two normalisation axes — the single most common mistake

In the E-step you fix one English word and spread its probability over the Chinese words: the denominator sums down a column. In the M-step you fix one Chinese word and spread it over the English words: the denominator sums across a row. Getting these the same way round is the whole trick.

Step 1 — count everything first

第一步：怎么把数数对（这里数错后面全错）

数三样东西，按这个顺序来：

  1. 先把每句话拆成 bigram（相邻两词一对），写在草稿纸上。注意：句子和句子之间不配对（最后那个词不跟下一句的第一个词配）。
  2. V = 不重复的单词个数。同一个词出现多次只算一个。比如 corpus 里有 8 句话但只有 9 个不同的词，V 就是 9。
  3. 再把相同的 bigram 合并计数，得到每个 bigram 出现几次。

最容易搞混的一点：N₁ 不是「某个词出现了几次」，而是「有多少种不同的 bigram 恰好只出现 1 次」。

举例：如果 bigram 表是这样的 —— machine translation 出现 3 次、translation works 出现 3 次、另外 6 种各出现 1 次 —— 那么 N₁ = 6（有 6 种只出现一次），N₂ = 0（没有出现两次的）。数的是「种类数」，不是「次数」。

Step 2 — maximum likelihood

MLE bigram
p(w₂ | w₁) = count(w₁, w₂) / count(w₁)

Worked — Quiz 1, Q2

p(translation | machine)3 / 4 = 0.75
p(model | machine)0 / 4 = 0

count(machine) = 4, and three of those are followed by translation. model never follows machine, so MLE gives it probability 0 — which is exactly the problem smoothing exists to fix.

Step 3 — Add-One smoothing

Add-One
padd1(w₂ | w₁) = (count(w₁, w₂) + 1) / (count(w₁) + V)

Worked — Quiz 1, Q3

seen: translation | machine(3+1)/(4+9) = 4/13 ≈ 0.308
unseen: model | machine(0+1)/(4+9) = 1/13 ≈ 0.0769

V = 9, so the denominator is 4 + 9 = 13 in both cases. The unseen bigram now has a small non-zero probability instead of 0.

Quiz 1, Q4 — interpretation, 1 mark

Add-One assigns a small non-zero probability to the unseen bigram, so a sentence containing machine model no longer receives probability zero.

Step 4 — Good-Turing

Good-Turing does not add a constant. It adjusts the observed count r to an expected count r*, using how many n-grams have neighbouring counts.

Good-Turing adjusted count
r* = (r + 1) · Nr+1 / Nr

Nr = how many distinct n-grams occur exactly r times in the corpus.

Worked — Quiz 2, Q1 & Q2

N₁ 和 N₂ 到底怎么数

问自己两个问题，别想复杂：

  1. 把这张 bigram 表里所有不同的 bigram一行行列出来（每种只列一次）。
  2. 在每种后面写它出现几次。然后回头看这些「次数」：有几个是 1？→ 那就是 N₁。有几个是 2？→ 那就是 N₂。

举个迷你例子：假设不同 bigram 有 5 种，次数分别是 3、2、1、1、1 → 那么 N₁ = 3（三个 1），N₂ = 1（一个 2），N₃ = 1。

然后套公式：如果要求某个只出现 1 次的 bigram 的调整计数，就是 r* = (1+1) × N₂ / N₁。

注意 r* 不是概率。它只是「修正后的计数」，如果要变概率还得再除以总数。

bigram types occurring onceN₁ = 6
bigram types occurring twiceN₂ = 2
translate translation model (r = 1)r* = 2 × 2/6 = ⅔ ≈ 0.667

Only the count changes — 1 becomes 0.667. The adjusted count is then normally converted to a probability by dividing by the total, but the quiz stops at r*.

N₁ and N₂ mean different things

N₁ is not "the count of the word translation". It is the number of distinct bigram types whose count equals 1. List the distinct bigrams first, then tally how many have each count.

Step 5 — back-off

back-off：先判分支，再算数

拿到题先做一件事：数一下这个三元组出现过没有。

  1. 在语料里找 (w₁, w₂, w₃) 这三个词连在一起出现过几次。
  2. 次数 > 0 → 用上面那一支，直接用 α₃（题目会直接给你，或让你说「用三元组」）。
  3. 次数 = 0 → 用下面那一支，降一级：把前两个词丢掉，退成 bigram，算 d₃ × p(w₃ | w₂)。

降级之后要重新数：这时要数的不是三元组了，而是后两个词组成的 bigram 出现几次，再除以中间那个词的总次数。

p(w₃ | w₂) = count(w₂,w₃) ÷ count(w₂)

别忘了乘 d₃。这个 d 是折扣系数（<1），题目会给。不乘就少一步。

If a high-order n-gram was never seen, you cannot use it. Back-off drops to a lower order, scaled by a discount.

Trigram back-off
p₃BO(wi | wi−2, wi−1) =
  α₃(wi | wi−2, wi−1)      if count₃(wi−2, wi−1, wi) > 0
  d₃(wi−2, wi−1) · p₂BO(wi | wi−1)    otherwise

Fig 1. The branch test is always the first step, and it is worth a mark on its own. The corpus contains neural translation works and neural translation helps, but never neural translation model — so the count is 0 and you drop to the bigram.

Worked — Quiz 2, Q3

count₃(neural, translation, model)0 → lower branch
count(translation, model)1
count(translation)6
p(model | translation)1/6 ≈ 0.1667
p₃BO(model | neural, translation) = 0.6 × 1/6 = 0.10

Entropy

One formula, one calculation. The quiz states the entropy formula is not provided, so memorise it.

Entropy, in bits
H(X) = − Σx p(x) log₂ p(x)
熵怎么算：log₂ 手算技巧

这类题会考的 p 值就那么几个，把对应的 log₂ 背下来就秒算：

p(x)log₂ p(x)−p·log₂p（这一项的贡献）
0.50 = 1/2−10.500
0.25 = 1/4−20.500
0.125 = 1/8−30.375
0.10−3.3220.332
0.20−2.3220.464

做题步骤：

  1. 先把次数换成概率（次数 ÷ 总数），检查加起来 = 1。
  2. 一项一项算 −p × log₂p，写在旁边。
  3. 全部加起来就是 H(X)，单位写 bits。

两个省时间的小技巧：

  • 凡是 p = 0.5 或 p = 0.25 的项，贡献都正好是 0.5。看到 8/16、4/16 就可以直接写 0.500。
  • 算完自查：熵一定 ≤ log₂(种类数)，并且 ≥ 0。比如 3 种结果，答案必须小于 1.585；4 种结果必须小于 2。超出范围说明按计算器按错了。

Worked — Practice Quiz 2, Q1

The Chinese source term 方案 was rendered three ways across 16 translated sentences. Treating the observed relative frequencies as the distribution of the random variable X:

Distribution of the English rendering chosen by the MT system

16 sentences · hover a bar for its contribution to H(X)

Worked solution

1.1 probabilities8/16 = 0.50 · 4/16 = 0.25 · 4/16 = 0.25
1.2 formulaH(X) = −Σ p(x) log₂ p(x)
−0.50 log₂ 0.500.500
−0.25 log₂ 0.250.500
−0.25 log₂ 0.250.500
H(X) = 1.50 bits

A shortcut worth knowing

For p = 0.50 and for p = 0.25, the term −p log₂ p equals 0.5 in both cases (because log₂0.5 = −1 and log₂0.25 = −2). All three terms here contribute exactly the same amount, so H = 3 × 0.5 = 1.50 bits. If you spot this, you can skip most of the arithmetic — and it is an easy way to check your answer.

Sanity check

Entropy is bounded by 0 ≤ H ≤ log₂|X|. With three outcomes the maximum is log₂3 ≈ 1.585 bits; a uniform distribution would give exactly that. 1.50 sits just below, which is right — the distribution is nearly uniform but not quite.

MT evaluation

Three measures appear in the quizzes: WER, clipped unigram precision, and AER. All three are short arithmetic — the marks are in getting the counts right.

Word Error Rate

WER 怎么数 S、D、I

把参考译文和系统输出上下并排写，一个词一个词对过去。对不上的分三种：

情况算什么例子
两边都有，但词不一样S（替换）works → work
参考里有，输出里没有D（删除）参考有 the，输出漏了
参考里没有，输出多出来I（插入）输出多了个词

分母 N 是「参考译文」的词数，不是输出的词数，也不是两者的平均。这是最容易错的一步。

自查：WER 可以超过 100%（插入很多的时候）。如果算出来是负数或超过 200%，肯定是数错了。

WER is the minimum number of editing steps needed to turn the system output into the reference, divided by the reference length. It is a Levenshtein distance.

Word Error Rate
WER = (S + D + I) / N

S = substitutions · D = deletions · I = insertions · N = number of words in the reference

Fig 2. The output omits the (one deletion) and uses work where the reference has works (one substitution). No words were added, so I = 0.

Worked — Practice Quiz 2, Q2.1

S · D · I1 · 1 · 0
N (reference words)6
WER = (1 + 1 + 0) / 6 = 2/6 ≈ 0.333 → 33.3%

N is the reference length

Here the output has 5 words and the reference has 6. Dividing by 5 would give 0.40 — wrong. Always divide by the reference length. WER can exceed 100% when there are many insertions.

Clipped unigram precision

精确率：分母是「输出」的词数

两步：

  1. 把系统输出的每个词，逐个去参考译文里找有没有。找到就算命中（重复的要注意：参考里出现几次，最多只能算命中几次）。
  2. 命中数 ÷ 输出的词数。

关键区别：WER 的分母是参考长度，精确率的分母是输出长度。为什么？因为 WER 衡量「错了多少」，以标准答案为基准；精确率衡量「产出的东西里有多少是对的」，以产出为基准。

输出里那个多余的词（参考里没有的）会拉低精确率，因为它在分母里但不在分子里。

A simplified BLEU component. Count how many unigrams of the output appear in the reference, clipping each at the number of times it appears in the reference, then divide by the output length.

Worked — Practice Quiz 2, Q2.2

Reference: the model produces good translation
Output: the model generates good translation

output unigramsthe · model · generates · good · translation
matching against referencethe · model · good · translation
clipped matches4
Unigram precision = 4 / 5 = 0.80 (80%)

generates appears in the output but not the reference, so it contributes nothing. The denominator is the output length, 5 — not the number of matches.

Where BLEU fits

Full BLEU combines clipped precision over 1-, 2-, 3- and 4-grams, takes the geometric mean, and applies a brevity penalty. The quiz asks only for the unigram component with brevity penalty ignored, so stop at 4/5.

Alignment Error Rate

AER scores an automatic word alignment against a gold standard. The gold standard has two parts: sure links (definitely correct) and possible links (acceptable alternatives).

Alignment Error Rate
AER = 1 − ( |A ∩ S| + |A ∩ P| ) / ( |A| + |S| )

A = predicted links · S = sure links · P = possible links · |X| = how many links the set contains

Fig 3. The predicted set A has four links. Three of them — (1,1), (2,2), (3,3) — are in both the sure set S and the possible set P. The fourth, (4,5), is in A alone: (4,4) is possible but was not predicted.

Worked — Quiz 3, Q4.4

|A| · |S| · |P|4 · 3 · 4
|A ∩ S|3
|A ∩ P|3
AER = 1 − (3 + 3) / (4 + 3) = 1 − 6/7 = 1/7 ≈ 0.143

The biggest single block on the practice quiz. Two versions appear: a 2×2 probability table, and a set of four explicit alignments. Same three steps both times.

The shape of the problem

E 步和 M 步的「加总方向」为什么相反

想象那张概率表：行 = 英文单词，列 = 中文词。

机器翻译
machine0.600.20
translation0.100.70
  • E 步：固定一个英文词，看它可能来自哪个中文词 → 所以是横着看一行，把这一行的数加起来当分母。
    例：machine 这行 0.60 + 0.20 = 0.80。
  • M 步：固定一个中文词，看它会翻成哪个英文词 → 所以是竖着看一列，把这一列的数加起来当分母。
    例：机器 这列 0.75 + 0.125 = 0.875。

一句话记法：E 步「英文说了算」→ 按行；M 步「中文说了算」→ 按列。

自查方法：E 步算完，每一行的 γ 加起来必须 = 1；M 步算完，每一列的 t_new 加起来必须 = 1。对不上就是轴搞反了。

拿到 EM 题的操作流程

先认清题目给的是哪一种：

给什么怎么下手
给一张 t(e|f) 概率表直接按行归一化 → 得到 γ（= 期望计数）→ 再按列归一化 → 得到新表
给几个 alignment 和它们的 p(e,a|f)先把它们全部加起来得到 p(e|f) → 各自除以 p(e|f) 得到后验 → 再把属于同一词对的加起来当计数

通用四步：

  1. 求分母。概率表版本：每行求和。alignment 版本：所有 p(e,a|f) 求和。
  2. 求 γ / 后验。每个数除以它所在的那个分母。算完立刻检查：每行加起来 = 1。
  3. 把 γ 当期望计数 c(e,f)。注意一个词对可能由多个 alignment 贡献，要加在一起。
  4. 按列（源词）归一化。每个源词那一列的计数，除以这一列的总和。

省时间的做法：如果分母对所有项都一样（比如都是除以 0.680），可以先把分子加成整再除一次，比每项单独除再相加更不容易出错。

t_new(the | maison)0.125 / 1.066 ≈ 0.117

These sum to 1. Keep full precision in the intermediate counts if you can — if you round 0.941 to 0.94 first, the second value drifts to 0.883 anyway, but the first becomes 0.1175. The marking guide allows reasonable rounding.

Spotting this pattern fast

Every count here is sum of some posteriors, and every posterior is p(e,a|f) / 0.680. So you can add the joint probabilities first and divide once: c(house | maison) = (0.560 + 0.080)/0.680 = 0.640/0.680 = 0.941. Fewer operations, less rounding error.

Quiz 4 — Q1 · Embedding and softmax in a feed-forward neural LM

(1) What is the role of the word-embedding layer? (2) What does the softmax output represent when the model predicts the next word?

Model answer

Marksdiscrete → vector · similar words, similar vectors · vocabulary distribution · sums to 1

  • 1Embedding layer. Maps each word — a discrete index — to a dense continuous vector; words used in similar ways end up with similar vectors. It turns symbolic input into something the network can compute with, avoiding the sparsity of one-hot vectors.
  • 2Softmax output. A probability distribution over the whole vocabulary (sums to 1). Each entry is the model's estimated probability that the corresponding word comes next, given the preceding context.

Quiz 4 — Q2 · Recurrent history and long-distance context

(1) In an RNN language model, what is carried from one time step to the next? (2) What difficulty can a basic RNN have with very long-distance dependencies? (3) Name an architecture designed to handle them better — what internal state does it keep, and which three gates control the flow?

Model answer

Markshidden state · vanishing/exploding gradient · LSTM · cell state + three gates

  • 1A hidden state vector. At each step the RNN combines the current input with the previous hidden state to produce a new one — a running summary of everything read so far.
  • 2Vanishing / exploding gradients. Backpropagation through many steps repeatedly multiplies by the recurrent weights, so the gradient either shrinks towards 0 (the long-distance dependency is never learned) or grows without bound (training becomes unstable).
  • 3LSTM. Besides the hidden state it maintains an extra cell state — a memory channel. Three gates control it: the input gate (what new information to write), the forget gate (what to erase) and the output gate (how much of the cell state to expose as the hidden state).

Q6 [10 marks]

(6.1) Why is a zero probability for an unseen bigram a problem when calculating the probability of a complete sentence? (6.2) Explain in words how Add-One gives an unseen bigram a non-zero probability. (6.3) State one advantage. (6.4) State one limitation and explain why it distorts the model.

Model answer

Marksproduct → zero · +1 in the numerator · +V in the denominator · mass shift

  • 6.1 · 2A sentence probability is the product of its n-gram probabilities. One unseen bigram with probability 0 makes the whole product 0, so a perfectly ordinary sentence is judged impossible — and such sentences cannot be compared with each other either.
  • 6.2 · 3Adding a pseudo-count of 1 to the numerator takes an unseen pair from 0 to 1. Adding V to the denominator compensates: the word could be followed by any of V vocabulary items and each has just been given an extra count, so the total must grow to keep the distribution summing to 1.
  • 6.3 · 2Unseen n-grams get a non-zero probability, so no sentence is driven to zero; the method is simple.
  • 6.4 · 3It adds 1 to every n-gram alike, including ones already well estimated. This moves probability mass away from observed events and gives it to the enormous number of unseen ones. Because V is large the denominator inflates, so the probabilities of observed pairs are seriously deflated — flattening the difference between frequent and rare events.

(7.1) In the formula, what do r and Nᵣ represent? (7.2) Why replace an observed count r with an adjusted count r*? (7.3) Where does the probability mass for unseen events come from? (7.4) Give one reason Good-Turing is more data-sensitive than simply adding one.

Model answer

Marksr = observed count · Nᵣ = number of types · discount to fund unseen · N₁/N

  • 7.1 · 2r = the number of times an n-gram was actually observed. Nᵣ = the number of distinct n-grams whose count equals exactly r (the frequency of frequencies). It counts types, not occurrences.

  • 7.3 · 3From the observed events. For small counts — especially r = 1 — the adjusted count r* is less than r, so observed counts are discounted and the freed mass is reassigned to n-gram types that never appeared. Classically the mass reserved for unseen events is about N₁ / N.

Marksunseen trigram = 0 · three-level back-off · d rescales the mass · better generalisation

  • 8.1 · 2An unseen trigram has MLE probability 0, and the product makes the whole sentence 0 — even though its bigram and unigram evidence may be strong. Discarding that lower-order evidence is wasteful.

Q9 [15 marks]

In the Figure 1 architecture: (9.1) What is the function of the Encoder, and what should it produce? (9.2) What is the function of Attention, and why is it useful? (9.3) What is the function of the Decoder? (9.4) Why is attention preferable to forcing the source into one fixed context vector?

Model answer

Marksone state per source word · weighted sum · word-by-word generation · fixed-vector bottleneck

  • 9.1 · 4Encoder reads the source sentence word by word (embedding, then RNN/LSTM) and produces a hidden state for every source position — not just one final vector. That sequence of states is the source representation, and it is what attention reads.
  • 9.2 · 4Attention takes a weighted sum over all encoder states at every decoding step, with weights reflecting how relevant each source word is to the target word being generated. Different target words need different source words (generating Haus should look mainly at house), so it gives the decoder dynamic, selective access to the source — in effect a soft alignment.
  • 9.3 · 3Decoder is an RNN/LSTM that generates the translation word by word. At each step it takes the previously generated word, its own hidden state, and the context vector from attention, and outputs a probability distribution over the whole target vocabulary.
  • 9.4 · 4The older model compresses the entire source into one fixed-length vector that the decoder sees throughout — an information bottleneck: the longer the sentence, the more is lost, and the decoder can never look back at a specific source word. Attention keeps all encoder states, so the decoder can access every source word at every step and weight them as needed. Long sentences, long-distance dependencies and word-order differences are all handled better.

Q5 · IBM Model 1 and AER [12 marks]

Source le chat, target the cat. Ignore NULL. The current model gives p(e, a | f) = 0.480 for (the→le, cat→chat), 0.020 for (the→le, cat→le), 0.090 for (the→chat, cat→chat), and 0.010 for (the→chat, cat→le).
(a) Compute p(e | f) and all four posterior alignment probabilities. Which alignment is most probable?
(b) Give the expected counts c(the | le), c(cat | le), c(the | chat) and c(cat | chat).
(c) Update the probabilities for the source word chat.
(d) A predicted alignment set A = {(1,1), (2,2), (3,1), (4,3)} is scored against S = {(1,1), (2,2), (3,1)} and P = {(1,1), (2,2), (3,1), (4,2)}. Compute the AER.

Answer

(a) p(e | f) = 0.480 + 0.020 + 0.090 + 0.010 = 0.600

p(a₁ | e, f) — the→le, cat→chat0.480/0.600 = 0.800
p(a₂ | e, f) — the→le, cat→le0.020/0.600 = 0.033
p(a₃ | e, f) — the→chat, cat→chat0.090/0.600 = 0.150
p(a₄ | e, f) — the→chat, cat→le0.010/0.600 = 0.017

Sum = 1.000 ✓ Most probable: a₁, the diagonal.

(b) Add the posteriors of the alignments containing each pair.

c(the | le) = a₁ + a₂0.800 + 0.033 = 0.833
c(cat | le) = a₂ + a₄0.033 + 0.017 = 0.050
c(the | chat) = a₃ + a₄0.150 + 0.017 = 0.167
c(cat | chat) = a₁ + a₃0.800 + 0.150 = 0.950

(c) Denominator for chat = 0.167 + 0.950 = 1.117

t_new(the | chat)0.167 / 1.117 ≈ 0.149
t_new(cat | chat)0.950 / 1.117 ≈ 0.851

These sum to 1 ✓

Q6 · Neural LM [6 marks]

(a) Why does a language model need a smoothing method at all? (b) In a basic RNN language model, what is passed from one time step to the next, and why does that make very long sentences hard to learn? (c) Name the architecture that addresses this and list its three gates.

Answer

(a) Maximum likelihood assigns probability 0 to any n-gram that was never observed in the training corpus. Because sentence probability is a product over its n-grams, a single unseen n-gram drives the whole sentence to 0. Smoothing reserves some probability mass for unseen events.

(b) A hidden state vector summarising the history so far. Over many time steps the gradient is repeatedly multiplied by the recurrent weights, so it either vanishes — and the dependency is never learned — or explodes.

(c) LSTM. It keeps an extra cell state, controlled by the input gate, the forget gate and the output gate.
