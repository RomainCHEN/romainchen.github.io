Digital Logic

Six gates, their symbols and truth tables, how to build any gate from NAND or NOR, and how to turn an expression into a circuit and name it.

Definitions

  • Digital electronics — the study of digital signals and the engineering of devices that use or produce them; contrasted with analog electronics. Complex devices may have simple electronic representations of Boolean logic functions.
  • Boolean logic — the algebra whose variable values are the truth values true and false, denoted 1 and 0. Applied to circuits this is digital logic.

Three symbol standards

MIL/ANSI — the distinctive shapes above (D for AND, shield for OR, triangle plus bubble for NOT, extra arc for XOR). IEC — a rectangle containing & for AND, ≥1 for OR, 1 for NOT, =1 for XOR. DIN — the third variant shown in the slides.

NAND and NOR are universal: either one alone can build every other gate. Two constructions from the slides.

Designing a circuit from an expression

The method

  1. NOT gate on every complemented variable, so each literal you need is available as a wire.
  2. The outermost operation decides the final gate. Multiplications and additions are applied last.
  3. Build in pairs, left to right. A 2-input gate takes two signals, so a three-way AND becomes two cascaded ANDs. Label every intermediate wire.
  4. Name the function from the truth table or from De Morgan.

Where marks are lost

  • Naming it after the gate. "AND" is wrong when the inputs are complemented. Name the function.
  • Three inputs into one AND. The question says 2-input, 1-output — cascade two gates instead.
  • No label on the intermediate wire. Unlabelled fan-out looks like an error.
PART 02

Simplified DES

A hand-computable Feistel cipher with the same skeleton as DES: an initial permutation, two rounds of a key-dependent function, and a final inverse permutation.

Parameters

ParameterSimplified DESDES (contrast)
Plaintext / ciphertext block8 bits64 bits
Key10 bits56 bits
Rounds216
Round keysK1, K2 — 8 bits eachK1 … K16 — 48 bits each
Round keys generated byPermutations and left shifts of the keySame idea, larger tables
StructureFeistel network — the round function output is XORed onto one half. Decryption is the same machine with the round keys in reverse order.

CT = IP⁻¹ ∘ fK2 ∘ SW ∘ fK1 ∘ IP (PT)
PT = IP⁻¹ ∘ fK1 ∘ SW ∘ fK2 ∘ IP (CT)

Why decryption works

fK leaves the right half untouched — it only XORs a value onto the left half. The untouched half therefore tells you exactly what it was, and XORing the same value again removes it. Undo the rounds in reverse order with the keys in reverse order and you recover the input exactly.

Fig 3. The complete machine. Both columns run IP → fK → SW → fK → IP⁻¹. The same key material is used; only the order it is applied in changes.

Key generation

Fig 4. LS-1 shifts each 5-bit half left by one. LS-2 shifts the LS-1 output by two more — not the P10 output. Dots mark where the shifted halves branch.

Reading a permutation table

In IP = {2, 6, 3, 1, 4, 8, 5, 7}, output position i takes input position P[i]. So IP of 1001 0101 is b₂ b₆ b₃ b₁ b₄ b₈ b₅ b₇ = 0101 1100. IP⁻¹ is a separate table, not a reversal.

Traps that cost the most marks

  • LS-2 on the wrong value. It applies to the LS-1 output. 01011 → LS-1 → 10110 → LS-2 → 11010.
  • XORing the wrong half. The round key XORs with E/P(R), never with L.
  • Dropping the SW. The swap between rounds is compulsory.
  • Using IP where IP⁻¹ belongs. Different tables.
  • Wrong key order in decryption. K2 first, then K1.

Security

The key is 10 bits, so there are 2¹⁰ = 1024 keys — brute force is trivial. Knowing a plaintext–ciphertext pair does not yield the key: recovering it is very hard other than by exhaustion over that tiny keyspace.

Digital Logic

L1Design the digital logic for D = (~A)(~B)(~C) using 2-input, 1-output basic gates (AND, OR, NOT). What is the particular name of this logic?

Very high — this was Quiz #3b

Model answer

Gates: 3 NOT gates (for A′, B′, C′) and 2 two-input AND gates. First AND: X = A′B′. Second AND: D = X · C′. Label the wire X.

Name: 3-input NOR, because D = A′B′C′ = (A+B+C)′ by De Morgan. Truth table has a single 1, in row A=B=C=0.

Draw the circuit as in Fig 3.

L2Draw the MIL/ANSI symbols and give the truth table for the AND, OR, NOT, NAND, NOR and XOR gates.

High — the entire Digital Logic 2/5 to 5/5 block

Model answer

Reproduce the six cards in Gate reference: D-shape for AND, shield for OR, triangle plus bubble for NOT, and the bubble added to AND and OR for NAND and NOR, extra arc for XOR. State each expression — A·B, A+B, A′, (A·B)′, (A+B)′, A⊕B — and the four-row (or two-row, for NOT) table.

L3Name the logic function for each expression, and say how many gates it takes: (a) A′B′ (b) A′ + B′ (c) (A+B)′ (d) A′B + AB′.

Medium–high — the naming skill, applied

Model answer

(a) 2 NOT + 1 AND → NOR, since A′B′ = (A+B)′.
(b) 2 NOT + 1 OR → NAND, since A′ + B′ = (A·B)′.
(c) 1 NOR → NOR.
(d) 2 NOT + 2 AND + 1 OR → XOR, the sum-of-products form.

L4Why are NAND and NOR called universal gates? Show how to build a NOT and an XOR from NAND gates only.

Medium — the "Variation of NOT Gate" and "XOR Composition" slides

Model answer

They are universal because any other gate can be constructed from copies of one of them alone.

NOT from NAND: tie both inputs to A. Output = (A·A)′ = A′. NOT from NOR: tie both inputs to A. Output = (A+A)′ = A′.

XOR from NAND: 4 gates — one NAND on A and B, one NAND on A with that output, one NAND on B with that output, one NAND on those two results. XOR from NOR: 5 gates. See Fig 1 and Fig 2.

L5State De Morgan's laws. Use them to show that A′B′C′ and (A+B+C)′ are the same function.

Medium — supports the naming in L1

Model answer

(A · B)′ = A′ + B′ and (A + B)′ = A′ · B′ — push a bar through and swap the operator.

Apply the second law twice: (A + B + C)′ = (A + B)′ · C′ = A′ · B′ · C′. The two expressions are identical, which is why the circuit in L1 is a NOR.

S3Decrypt the ciphertext 1101 0000 with the same key.

High — the exercise slide asks for decryption straight after encryption

Model answer

Run the identical structure with K2 first, then K1. IP of 1101 0000 is 1001 1000; after fK2 and the swap you get 1000 0000; after fK1 and IP⁻¹ the block returns to 0000 0000.

State the principle: decryption is the same machine with the round keys reversed, because fK leaves the right half untouched and XOR is its own inverse. Verify your own working in the stepper.

S4A 4-bit input 1011 is fed to S0. What is the output? Explain the row/column rule.

High — S-boxes are the only nonlinear part and are easy to test

Model answer

Row = bits 1 and 4 = 11 = 3. Column = bits 2 and 3 = 01 = 1. So read row 3, column 1 of S0: S0[3][1] = 1.

Write the result as two binary digits: output = 01. Each S-box maps 4 bits to 2 bits; S0 handles bits 1–4 of the XOR result and S1 handles bits 5–8.

S5Give the parameters of Simplified DES and state the security of the cipher.

Medium–high — the "Simplified DES (1/10)" and summary slides

Model answer

8-bit plaintext block, 8-bit ciphertext block, 10-bit key, 2 rounds. Round keys are generated from the key using permutations (P10, P8) and left shifts (LS-1, LS-2). Encryption is initial permutation, round function, swap halves, round function, inverse initial permutation.

Security: 10-bit key means 2¹⁰ = 1024 possible keys, so brute force is trivial. Knowing a plaintext and its ciphertext does not directly reveal the key — determining it is very hard apart from exhaustive search.

S6Why can the S-DES decryption network use the same structure as encryption, and what changes?

Medium — the summary slide states it, the Feistel slide explains it

Model answer

The round function fK(L, R) = (L ⊕ F(R, SK), R) does not modify R — it only XORs F(R, SK) onto L. So each round is invertible given the same subkey.

Decryption therefore uses the identical IP → fK → SW → fK → IP⁻¹ structure. The only change is the order of the round keys: decryption applies K2 then K1, reversing the encryption order. Formally, PT = IP⁻¹ ∘ fK1 ∘ SW ∘ fK2 ∘ IP(CT).

S7What are the design principles and parameters to consider when designing a secure block cipher?

Medium — printed on the exercise slide

Model answer

Parameters: block size (larger gives more diffusion — DES 64, AES 128); key size (larger resists brute force — DES 56 is too short, AES 128/192/256); number of rounds (DES 16, AES 10–14).

Design properties: subkey generation and the round function F should be complex; the cipher should achieve both confusion (hiding the key–ciphertext relationship, via substitution / S-boxes) and diffusion (spreading each input bit over many output bits, via permutation and mixing). Both are repeated over many rounds with the key re-mixed each round, so an attacker cannot pre-compute the cipher's behaviour.

S8Apply IP to the 8-bit block 1001 0101 and explain what IP⁻¹ does.

Medium — a quick, easily marked bit-manipulation item

Model answer

IP = {2, 6, 3, 1, 4, 8, 5, 7}, so output bit i takes input bit P[i]:

b₂ b₆ b₃ b₁ b₄ b₈ b₅ b₇ = 0 1 0 1 1 1 0 0 = 0101 1100

IP⁻¹ = {4, 1, 3, 5, 7, 2, 8, 6} undoes it at the end of the cipher. It is a separate table, not the reverse ordering of IP.

Distinguish substitution from permutation, and say where each appears in S-DES.
Answer

Substitution replaces an element, or group, with a corresponding different one. In S-DES: the S-boxes, where 4 bits in become a different 2 bits out.

Permutation rearranges a sequence — nothing added, deleted or replaced, only the order changes. In S-DES: P10, P8, IP, IP⁻¹, E/P and P4.

RECAP

Last-hour recap

Digital Logic

The six gates

AND   Q = A · B
OR    Q = A + B
NOT   Q = A′
NAND Q = (A·B)′
NOR   Q = (A+B)′
XOR   Q = A ⊕ B

Facts asked directly

  • NAND and NOR are universal.
  • Tie both inputs of NAND or NOR → NOT.
  • XOR = 4 NANDs or 5 NORs.
  • Bubble = inversion. IEC: & AND, ≥1 OR, =1 XOR.

De Morgan + naming

(A·B)′ = A′+B′
(A+B)′ = A′·B′

A′B′C′ = (A+B+C)′ = NOR
A′+B′ = (A·B)′ = NAND

Design procedure

  1. NOT on every complemented variable.
  2. Outermost operation = final gate.
  3. Build in pairs; label intermediates.
  4. Name from the truth table or De Morgan.
